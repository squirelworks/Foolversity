# Changelog

## 1.0.0

Makes the files. Foolcourse reads them.

- `python3 foolversity` prints the commands
- `student`, `school`, `curriculum` write `.fcs`, `.school.json`, and a curriculum file
- `gui` opens a window with the same three forms
- `--out` writes into a Foolcourse tree (`_student/`, `_curriculum/`)
- Schools go to `_schools/` beside the program unless `--out` is set
- Own student writer. Does not import Foolcourse or Foolbook

Depends on Foolcourse 1.0.0.
